Spesifikasi Arsitektur: SEC EDGAR HNWI Signal Scraper
1. Parameter Sistem Utama
Target: Ekstraksi Form 4, Form 144, dan 8-K (Item 1.01/2.01) dari sistem SEC EDGAR.

Batas Infrastruktur (Rate Limit): Maksimal 10 permintaan HTTP per detik. Kegagalan mematuhi ini akan memicu pemblokiran IP. Wajib mengimplementasikan mekanisme queue dengan pembatas laju (rate limiter) dan exponential backoff untuk kegagalan jaringan (HTTP 429).

Identitas Jaringan: Header HTTP wajib menyertakan User-Agent: NamaProyek/1.0 (nama@domain.com) dan Accept-Encoding: gzip, deflate.

2. Manajemen State & Anti-Duplikasi (Persistence Layer)
Gunakan basis data relasional (contoh: SQLite) untuk mengelola memori sistem dan mencegah redundansi data.

Skema Tabel processed_filings:

accession_number (PRIMARY KEY, String): Nomor identifikasi unik dokumen SEC.

form_type (String): 4, 144, atau 8-K.

processed_at (Timestamp): Waktu ekstraksi.

Logika Eksekusi: Sebelum mengunduh body dokumen XML/JSON penuh, periksa accession_number dari umpan langsung (live feed) ke dalam basis data. Abaikan jika entri sudah ada. Catat entri baru hanya setelah ekstraksi sukses.

3. Mesin Pengambilan Data (Polling & Paginasi)
Hapus penggunaan parameter waktu statis.

Jendela Waktu (Rolling Window): Konfigurasi waktu secara dinamis. Tetapkan start_date sebagai Waktu Saat Ini - 24 Jam dan end_date sebagai Waktu Saat Ini.

Paginasi Eksplisit: Implementasikan perulangan (loop) pada parameter from (offset) di titik akhir API. Sistem harus terus menggeser kursor data (misal: 0, 100, 200) dan hanya berhenti jika respons mengembalikan array kosong atau mencapai batas waktu start_date.

Cache-Busting: Sisipkan parameter timestamp acak (waktu UNIX epoch) pada akhir query string (misal: ?ts=1710000000) untuk memaksa peladen memberikan data mutakhir, bukan data tembolok (cache).

4. Ekstraksi Struktural & Logika Bisnis
Gunakan parser XML/JSON deterministik (contoh: lxml di Python atau cheerio di Node.js), hindari penggunaan Regex untuk DOM.

Form 4 (Penjualan Eksekutif):

Ekstrak node <transactionShares> dan <sharesOwnedFollowingTransaction>.

Kalkulasi rasio menggunakan pembagian skalar: transactionShares / (transactionShares + sharesOwnedFollowingTransaction).

Filter Mutlak: Gugurkan dokumen jika rasio penjualan < 0.05.

Form 144 (Sinyal Niat):

Ekstrak total saham yang akan dijual dan estimasi nilai pasar agregat.

8-K (Likuiditas M&A):

Gunakan API EFTS (efts.sec.gov/LATEST/search-index).

Kueri pencarian teks: "acquisition" OR "merger" OR "definitive agreement".

Filter Mutlak: Hanya proses tipe dokumen 8-K dengan metadata klasifikasi Item 1.01 atau 2.01.

5. Mesin Penilaian (Scoring Engine)
Klasifikasikan urgensi prospek berdasar tindakan finansial aktual.

Kritis (Critical): Rasio Penjualan > 50% ATAU Nilai Transaksi Aktual > $10.000.000.

Tinggi (High): Rasio Penjualan 20%-50% ATAU Entitas menduduki posisi C-Level (CEO, CFO, CTO) dengan likuidasi > $1.000.000.

Menengah (Medium): Rasio Penjualan 5%-20%.

6. Konstruksi Output
Simpan data bersih ke dalam berkas output_signals.csv atau masukkan kembali ke tabel SQLite signals dengan struktur matriks berikut:
company_name, ticker, insider_name, title, form_type, transaction_value, sell_ratio, urgency_score, filing_url, signal_date


### 1. Spesifikasi Tumpukan Teknologi (Tech Stack)

* **Runtime:** Node.js (v20+)
* **Bahasa Eksekusi:** TypeScript (via `tsx`)
* **Basis Data:** `better-sqlite3` (Operasi disk sinkron, memori persisten)
* **Pembatas Laju (Rate Limiter):** `bottleneck` (Mencegah blokir IP SEC)
* **Parser XML:** `fast-xml-parser` (Pemrosesan graf XML deterministik)
* **Klien Jaringan:** Native `fetch` API

### 3. Implementasi Sistem Inti (`scraper.ts`)

Buat berkas `scraper.ts` dan tempelkan logika eksekusi sekuensial berikut. Skrip ini memodelkan penarikan Form 4, manajemen state, dan kalkulasi rasio.

```typescript
import Database from 'better-sqlite3';
import Bottleneck from 'bottleneck';
import { XMLParser } from 'fast-xml-parser';

// 1. Inisialisasi Basis Data State & Output
const db = new Database('edgar_data.sqlite');
db.pragma('journal_mode = WAL');

db.exec(`
  CREATE TABLE IF NOT EXISTS processed_filings (
    accession_number TEXT PRIMARY KEY,
    form_type TEXT,
    processed_at DATETIME DEFAULT CURRENT_TIMESTAMP
  );
  CREATE TABLE IF NOT EXISTS hnwi_signals (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    company_name TEXT,
    ticker TEXT,
    insider_name TEXT,
    title TEXT,
    transaction_value REAL,
    sell_ratio REAL,
    urgency TEXT,
    signal_date TEXT,
    source_url TEXT
  );
`);

// 2. Pembatasan Laju (Limitasi SEC: Maks 10 req/sec)
const secLimiter = new Bottleneck({
  maxConcurrent: 1,
  minTime: 200 // Mengunci eksekusi di 5 permintaan per detik (Keamanan sistem)
});

const parser = new XMLParser({ ignoreAttributes: false, attributeNamePrefix: "@_" });

// 3. Wrapper Klien HTTP dengan Header Wajib SEC
const fetchSEC = secLimiter.wrap(async (url: string) => {
  const response = await fetch(url, {
    headers: {
      "User-Agent": "ValiverSystem/1.0 (admin@valiver.ai)", // Ganti dengan entitas valid jika perlu
      "Accept-Encoding": "gzip, deflate"
    }
  });
  if (response.status === 429) {
    throw new Error("HTTP 429: Rate Limit Exceeded. Backing off.");
  }
  if (!response.ok) {
    throw new Error(`HTTP Error: ${response.status} pada ${url}`);
  }
  return response.text();
});

// 4. Logika Eksekusi Form 4
async function runForm4Pipeline() {
  console.log("Membaca umpan langsung Form 4...");
  const atomFeedUrl = 'https://www.sec.gov/cgi-bin/browse-edgar?action=getcurrent&type=4&count=100&output=atom';
  const xmlData = await fetchSEC(atomFeedUrl);
  const feed = parser.parse(xmlData);
  const entries = feed.feed.entry || [];

  for (const entry of entries) {
    const title = entry.title; // Format: "4 - COMPANY NAME (CIK) (Issuer)"
    const urn = entry.id; // Format: "urn:tag:sec.gov,2008:accession.0001234567-24-000012"
    const accessionNumber = urn.split('.').pop();
    const cikMatch = title.match(/\((\d{10})\)/);
    const cik = cikMatch ? cikMatch[1] : null;

    if (!accessionNumber || !cik) continue;

    // Cek State (Hindari duplikasi)
    const exists = db.prepare('SELECT 1 FROM processed_filings WHERE accession_number = ?').get(accessionNumber);
    if (exists) continue;

    const accessionNoDashes = accessionNumber.replace(/-/g, '');
    const filingUrl = `https://www.sec.gov/Archives/edgar/data/${cik}/${accessionNoDashes}/${accessionNumber}.txt`;

    try {
      console.log(`Mengunduh arsip XML: ${accessionNumber}`);
      const rawText = await fetchSEC(filingUrl);
      
      // Ekstraksi blok XML dari file SGML .txt
      const xmlMatch = rawText.match(/<XML>([\s\S]*?)<\/XML>/i);
      if (!xmlMatch) {
         // Tandai gagal/selesai agar tidak diulang
         db.prepare('INSERT INTO processed_filings (accession_number, form_type) VALUES (?, ?)').run(accessionNumber, '4');
         continue;
      }

      const form4Data = parser.parse(xmlMatch[1]);
      const ownershipDoc = form4Data.ownershipDocument;
      if (!ownershipDoc) continue;

      const companyName = ownershipDoc.issuer?.issuerName;
      const ticker = ownershipDoc.issuer?.issuerTradingSymbol;
      const insiderName = ownershipDoc.reportingOwner?.reportingOwnerId?.rptOwnerName;
      const title = ownershipDoc.reportingOwner?.reportingOwnerRelationship?.officerTitle || "Director";
      
      let totalSharesSold = 0;
      let sharesRemaining = 0;
      let transactionValue = 0;

      // Parsing transaksi non-derivatif (Saham Biasa)
      const transactions = [].concat(ownershipDoc.nonDerivativeTable?.nonDerivativeTransaction || []);
      
      for (const t of transactions) {
        if (t.transactionAmounts?.transactionAcquiredDisposedCode?.value === 'D') { // D = Disposed/Dijual
          const shares = parseFloat(t.transactionAmounts.transactionShares?.value || '0');
          const price = parseFloat(t.transactionAmounts.transactionPricePerShare?.value || '0');
          totalSharesSold += shares;
          transactionValue += (shares * price);
          sharesRemaining = parseFloat(t.postTransactionAmounts?.sharesOwnedFollowingTransaction?.value || '0');
        }
      }

      // 5. Filter & Kalkulasi Rasio
      if (totalSharesSold > 0) {
        const sellRatio = totalSharesSold / (totalSharesSold + sharesRemaining);
        
        let urgency = "LOW";
        if (sellRatio > 0.5 || transactionValue > 10000000) urgency = "CRITICAL";
        else if (sellRatio > 0.2 || transactionValue > 1000000) urgency = "HIGH";
        else if (sellRatio > 0.05) urgency = "MEDIUM";

        if (sellRatio >= 0.05) {
          db.prepare(`
            INSERT INTO hnwi_signals 
            (company_name, ticker, insider_name, title, transaction_value, sell_ratio, urgency, signal_date, source_url)
            VALUES (?, ?, ?, ?, ?, ?, ?, DATE('now'), ?)
          `).run(companyName, ticker, insiderName, title, transactionValue, sellRatio, urgency, filingUrl);
          
          console.log(`[SIGNAL DITEMUKAN] ${insiderName} (${companyName}) - Rasio: ${(sellRatio*100).toFixed(1)}%`);
        }
      }

      // Catat State
      db.prepare('INSERT INTO processed_filings (accession_number, form_type) VALUES (?, ?)').run(accessionNumber, '4');

    } catch (err) {
      console.error(`Gagal memproses ${accessionNumber}:`, err);
    }
  }
  console.log("Siklus selesai.");
}

runForm4Pipeline();

```

### 4. Instruksi Pengujian End-to-End (E2E)

1. **Eksekusi Skrip:**
Jalankan perintah berikut untuk menginisiasi pipeline ekstraksi.
```bash
npx tsx scraper.ts

```


2. **Pemantauan Log:**
Terminal akan menampilkan proses pembacaan XML dan mematuhi batas laju (jeda antar *request*). Sistem hanya akan mencetak `[SIGNAL DITEMUKAN]` jika menemukan direktur/eksekutif yang menjual saham dengan rasio di atas batas 5%.
3. **Verifikasi Integritas Basis Data:**
Buka basis data SQLite yang terbentuk menggunakan ekstensi peramban, aplikasi DBeaver, atau antarmuka baris perintah SQLite.

```bash
    sqlite3 edgar_data.sqlite
    sqlite> SELECT count(*) FROM processed_filings;
    sqlite> SELECT * FROM hnwi_signals LIMIT 1;
    sqlite> .quit
    ```
4.  **Verifikasi Amnesia State (Anti-Duplikasi):**
    Jalankan `npx tsx scraper.ts` untuk kedua kalinya. Skrip harus selesai hampir seketika karena sistem akan membaca `accession_number` dari SQLite dan melewati pengunduhan XML untuk dokumen yang sama.
